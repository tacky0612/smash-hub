# {{instance_name}} 利用規約

この利用規約（以下「本規約」）は、{{instance_name}}（以下「本サービス」）の運営者（以下「運営者」）が提供する、大乱闘スマッシュブラザーズ SPECIAL の対戦マッチング・結果報告・レーティングのサービスの利用条件を定めます。本サービスを利用する人（以下「利用者」）は、アカウントを登録する前に本規約をお読みください。登録した時点で、本規約に同意したものとします。

## 1. 本サービスについて

- 本サービスは有志による非公式のファンサイトであり、任天堂株式会社とは一切関係ありません。「大乱闘スマッシュブラザーズ」は任天堂株式会社の登録商標です。
- 本サービスは、オープンソースのソフトウェア SmashHub で動いています。SmashHub の開発プロジェクトの方針（運営ポリシー）は {{policy_url}} で公開されています。
- 本サービスは、SmashHubプロトコルで連合する他のサイト（以下「連合先」）と、対戦記録と対戦募集を共有します。

## 2. アカウント

- ログインには外部のサービス（Discord 等）のアカウントを使います。本サービスはパスワードを扱いません。
- 外部のサービスのアカウント1つにつき、本サービスのアカウントは1つまでです。
- 表示名は公開されます。本名・連絡先・他人を不快にさせる言葉は使わないでください。
- アカウントを他人に譲ったり、貸したりしないでください。

## 3. 公開・共有される情報

- 確定した対戦記録（対戦日時・両者のアカウント ID・使用ファイター・勝敗）と表示名は公開され、連合先にも複製されます。
- 確定した対戦記録は、連合で記録を失わないようにするため、後から削除できません。誤りや不正があった記録は、運営者が無効化（レート計算から除外）します。
- 本サービスは、メールアドレス・パスワード・外部のサービスのユーザー名を保存しません。外部のサービスの利用者 ID は、元に戻せない形（識別子ハッシュ）にしてから保存します。
- 不正なアクセスへの対策のため、接続元の IP アドレスを含むアクセスログを一定期間（初期値 14日）保存し、その後削除します。アクセスログは連合先と共有しません。

## 4. 対戦のルール

- 対戦は、SmashHub の標準ルール（{{rules_url}}）に従って行ってください。
- 結果は正しく報告してください。

## 5. 禁止事項

次の行為を禁止します。

- 改造した本体・ソフトやチートツールの使用、不正な入力機器（連射・マクロ・自動操作ができる機器等）の使用
- 八百長（わざと負ける、負けを報告してレートを渡す等）
- 虚偽の報告（負けたのに勝ちと報告する、決着したのに中止と報告する等）、虚偽の通報
- 晒し（相手の名前や画面を SNS に載せて非難すること）、暴言・挑発
- 複数のアカウントを使ってレートを操作すること
- 本サービスや連合先の運営を妨げる行為、法令に違反する行為

## 6. 通報と運営者の対応

- 禁止事項に当たる行為を見つけたら、相手のユーザーページから通報してください。通報したことや通報者が誰かは、相手に知らせません。
- 通報の内容は運営者だけが見ます。対応が終わってから 30日で削除します。
- 運営者は、通報の内容や対戦の記録を確認し、次の段階で対応します。段階の進め方や利用停止の期間は、違反の内容と回数に応じて運営者が判断します。
  - 注意: 運営者から注意します。記録には残しますが、利用は制限しません。
  - イエローカード: 警告です。重なると利用停止の対象になります。
  - レッドカード: レーティング対戦の利用停止（期間付きまたは無期限）です。
- 八百長などの不正があった対戦の記録は、対戦から 7日以内であれば無効化します。
- 対応に納得できない場合は、下記の問い合わせ先に申し立ててください。

## 7. 免責

- 本サービスは無償で、現状のまま提供します。運営者は、本サービスが中断なく動くこと、レートや記録に誤りがないことを保証しません。
- 運営者は、事前に告知したうえで本サービスを終了することがあります。終了しても、確定した対戦記録は連合先に残ります。
- 利用者どうしのトラブルは、当事者の間で解決してください。運営者は、通報に基づく対応のほかは関与しません。

## 8. 本規約の変更

運営者は、必要に応じて本規約を変更することがあります。重要な変更は、本サービス上で告知します。
