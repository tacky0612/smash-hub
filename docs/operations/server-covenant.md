# サーバー運用者の約束事（Server Covenant）

> ステータス: **Draft**。Phase 3 で連合の参加条件として確定します。

連合に参加する運営者（Smash-hub のソフトウェアを使うインスタンス、および連合プロトコルを独自に実装した他のサイト）は、次の事項に同意するものとします。
これは利用者が「どのインスタンスを選んでも安心して使える」ための最低限の約束です。

**営利・非営利は問いません**（[ADR 0007](../adr/0007-federation-open-to-commercial-sites.md)）。各運営者の営利活動や、それによる任天堂株式会社その他の権利者の権利の侵害について、連合プロトコルおよび Smash-hub プロジェクトは責任を負わず、責任は各運営者が負います。約束事に反するインスタンスは、各インスタンスが連合ポリシーで拒否できます。

## 1. ポリシーの遵守

- [運営ポリシー](../policy.md) の「1. 商標・著作物の取り扱い」と、「3. プレイヤーのデータ」のうち「3.1 対戦記録は公開・複製される」「3.3 削除とエクスポート」に従うこと（「2. 非営利」はプロジェクト自身の方針であり、参加条件ではない。「3.2 最小限の個人情報」は下の「3. 利用者の保護」に読み替える）。特に以下を守る。
  - 任天堂の利用許可が出ている素材以外を使わない。
  - 非公式のファンサイトである旨を表示する。
  - 営利で運営する場合も、利用者の情報を収集するトラッキングを行わない（広告を掲載する場合も同様）。

## 2. 記録の誠実な取り扱い

- 対戦記録を改ざんしない。架空のアカウント・対戦を作らない。
- 連合先から受け取った記録を、連合ポリシーに基づく正当な理由なく破棄・隠蔽しない。
- 自インスタンスのログを連合先に提供し続ける（運用中は pull を拒否しない）。
- サイト独自のレートを併用する場合は、連合レートと区別できる別の名前で表示する（[レーティング](../domain/rating.md) の「6. 連合レート」）。

## 3. 利用者の保護

- 利用者の個人情報を連合で共有しない。連合に出すのは、[連合プロトコル](../architecture/federation.md) の「4. 共有される事実」だけとする（プロトコルは個人情報を取り扱わない → 同「4.4 個人情報を扱わない」）。
- サイトの中でどの情報を保存するか、どの認証方式を使うかは各運営者の責任とし、適用される法令に従って管理する。Smash-hub のソフトウェアを使うインスタンスは、[データ保護](../security/data-protection.md) に定める以上の情報を保存しない。
- アクセス解析・トラッキングを設置しない。
- 識別子ハッシュ・セッション・アクセスログなど、サイトの中だけで使う情報を連合で共有しない。Smash-hub のソフトウェアを使うインスタンスは、これらを [セキュリティポリシー](../security/README.md) に従って管理する。
- 利用者が求めた場合、対戦履歴のエクスポートとアカウント移行を妨げない。
- 利用規約とモデレーション方針をインスタンス情報ページで公開する。

## 4. 閉鎖時の責任

- 閉鎖する場合は、可能な限り **30日以上前** に閉鎖予告を利用者と連合へ通知する。
- 閉鎖までの間、利用者の移行と、自インスタンスのログの最終的な複製を受け付ける。

## 5. ソースコードの公開

- Smash-hub は [AGPL-3.0](../../LICENSE) です。ソフトウェアを改変して運用する場合は、利用者が改変後のソースコードを入手できるようにする（画面のフッターのソースコードへのリンクを改変版のリポジトリに設定する）。

## 6. 連絡先

- 他の運営者や権利者が連絡できる窓口を公開する。
