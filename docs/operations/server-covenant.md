# サーバー運用者の約束事（Server Covenant）

> ステータス: **Draft**。Phase 3 で連合の参加条件として確定します。

連合に参加する運営者（SmashHub のソフトウェアを使うインスタンス、および SmashHubプロトコルを独自に実装した他のサイト）は、次の事項に同意するものとします。
これは利用者が「どのインスタンスを選んでも安心して使える」ための最低限の約束です。

**営利・非営利は問いません**（[ADR 0011](../adr/0011-federation-participation-conditions.md)）。約束事は、連合で共有する記録の誠実さと、利用者の保護に絞っています。約束事に反するインスタンスは、各インスタンスが連合ポリシーで拒否できます。

> [!NOTE]
> **SmashHub プロジェクト自身の方針と、連合への参加条件は別です。** SmashHub のソフトウェアと、プロジェクトが運営・推奨するインスタンスは、任天堂の利用許可が出ている素材以外を使わず、非営利で運用し、アクセス解析・トラッキングを組み込みません（[運営ポリシー](../policy.md)）。
> 連合に参加する他のサイトには、これらを求めません。素材の利用・営利活動・アクセス解析等は各運営者の判断と責任で行い、それによる任天堂株式会社その他の権利者の権利の侵害や法令違反について、SmashHubプロトコルおよび SmashHub プロジェクトは責任を負いません。責任は各運営者が負います。

## 1. 表示

- 非公式のファンサイトである旨を表示する（公式のサービスと誤認されないため）。
- 確定した対戦記録が公開され、連合先に複製されることを利用者に明示し、同意を得る（[運営ポリシー](../policy.md) の「3.1 対戦記録は公開・複製される」）。

## 2. 記録の誠実な取り扱い

- 対戦記録を改ざんしない。架空のアカウント・対戦を作らない。
- 連合先から受け取った記録を、連合ポリシーに基づく正当な理由なく破棄・隠蔽しない。
- 自インスタンスのログを連合先に提供し続ける（運用中は pull を拒否しない）。
- サイト独自のレートを併用する場合は、SmashHub のレートを「SmashHubレート」という名前で表示し、独自のレートと区別する（[レーティング](../domain/rating.md) の「6. SmashHubレート」）。

## 3. 利用者の保護

- 利用者の個人情報を連合で共有しない。連合に出すのは、[SmashHubプロトコル](../architecture/federation.md) の「4. 共有される事実」だけとする（プロトコルは個人情報を取り扱わない → 同「4.4 個人情報を扱わない」）。
- サイトの中でどの情報を保存するか、どの認証方式を使うかは各運営者の責任とし、適用される法令に従って管理する。SmashHub のソフトウェアを使うインスタンスは、[データ保護](../security/data-protection.md) に定める以上の情報を保存しない。
- 識別子ハッシュ・セッション・アクセスログなど、サイトの中だけで使う情報を連合で共有しない。SmashHub のソフトウェアを使うインスタンスは、これらを [セキュリティポリシー](../security/README.md) に従って管理する。
- 利用者が求めた場合、対戦履歴のエクスポートとアカウント移行を妨げない。
- 利用規約とモデレーション方針をインスタンス情報ページで公開する。

## 4. 閉鎖時の責任

- 閉鎖する場合は、可能な限り **7日以上前** に閉鎖予告を利用者と連合へ通知する。
- 閉鎖までの間、利用者の移行と、自インスタンスのログの最終的な複製を受け付ける。

## 5. ソースコードの公開

- SmashHub は [AGPL-3.0](../../LICENSE) です。ソフトウェアを改変して運用する場合は、利用者が改変後のソースコードを入手できるようにする（画面のフッターのソースコードへのリンクを改変版のリポジトリに設定する）。

## 6. 連絡先

- 他の運営者や権利者が連絡できる窓口を公開する。
