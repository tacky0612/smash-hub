# サーバー運用者の約束事（Server Covenant）

> ステータス: **Draft**。Phase 3 で連合の参加条件として確定します。

Smash-hub のインスタンスを運営し、連合に参加する運営者は、次の事項に同意するものとします。
これは利用者が「どのインスタンスを選んでも安心して使える」ための最低限の約束です。

## 1. ポリシーの遵守

- [運営ポリシー](../policy.md) に従うこと。特に以下を守る。
  - 任天堂の利用許可が出ている素材以外を使わない。
  - 広告・有料機能等による収益化を行わない。
  - 非公式のファンサイトである旨を表示する。

## 2. 記録の誠実な取り扱い

- 対戦記録を改ざんしない。架空のアカウント・対戦を作らない。
- 連合先から受け取った記録を、連合ポリシーに基づく正当な理由なく破棄・隠蔽しない。
- 自インスタンスのログを連合先に提供し続ける（運用中は pull を拒否しない）。

## 3. 利用者の保護

- 利用者の個人情報を収集しない（[データ保護](../security/data-protection.md) に定める以上の情報を保存しない。アクセス解析・トラッキングを設置しない）。
- 識別子ハッシュ・セッション・アクセスログを連合で共有せず、[セキュリティポリシー](../security/README.md) に従って管理する。
- 利用者が求めた場合、対戦履歴のエクスポートとアカウント移行を妨げない。
- 利用規約とモデレーション方針をインスタンス情報ページで公開する。

## 4. 閉鎖時の責任

- 閉鎖する場合は、可能な限り **30日以上前** に閉鎖予告を利用者と連合へ通知する。
- 閉鎖までの間、利用者の移行と、自インスタンスのログの最終的な複製を受け付ける。

## 5. ソースコードの公開

- Smash-hub は [AGPL-3.0](../../LICENSE) です。ソフトウェアを改変して運用する場合は、利用者が改変後のソースコードを入手できるようにする（画面のフッターのソースコードへのリンクを改変版のリポジトリに設定する）。

## 6. 連絡先

- 他の運営者や権利者が連絡できる窓口を公開する。
