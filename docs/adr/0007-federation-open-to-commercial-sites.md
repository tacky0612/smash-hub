# 0007: 連合への参加に非営利を求めない

- ステータス: Accepted
- 日付: 2026-10-26

## 背景

- 当初は、SmashHub を使って運営するすべてのインスタンスに非営利を求め、[運用者の約束事](../operations/server-covenant.md) でも連合への参加条件にしていた。
- SmashHubプロトコルは「同じ対戦記録と同じ計算手順を共有する、レーティングの共通基盤」を目指している。独自の UI を持つ他の対戦サイト（広告などで収益を得ているものを含む）も参加できたほうが、記録が多くの場所に残り、プレイヤーの選択肢も増える。

## 決定

- **非営利は SmashHub の開発プロジェクト自身の方針** とする。プロジェクトは収益を得ず、プロジェクトが運営・推奨するインスタンスも非営利とする。
- **連合への参加には非営利を求めない。** SmashHub のソフトウェアを使うインスタンスも、プロトコルを独自に実装する他のサイトも、営利・非営利を問わず参加できる。
- 非営利以外の約束事（任天堂の利用許可のない素材を使わない、記録を改ざんしない、利用者の個人情報を連合で共有しない 等）は、引き続き連合への参加条件とする。
- 各運営者の営利活動や、それによる任天堂株式会社その他の権利者の権利の侵害について、本プロトコルおよび SmashHub プロジェクトは責任を負わない。責任は各運営者が負う。
- 約束事に反するインスタンスは、各インスタンスが連合ポリシー（拒否リスト）で拒否できる。

## 影響

- 運営ポリシー・運用者の約束事・README の記述を、プロジェクト自身の方針と参加条件に分けて書き直す。
- 営利のサイトが増えると、ファンサイトの範囲を超えた利用として権利者から問題視される可能性がある。プロジェクト自身が非営利を守り、その旨と免責を明記することで、プロジェクトと他の運営者の責任を分ける。
- 広告を掲載するサイトでも、利用者の情報を収集するトラッキングは、データ保護の約束事に反する。
