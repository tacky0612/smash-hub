# 0003: ライセンスを AGPL-3.0 とする

- ステータス: Accepted
- 日付: 2026-10-26

## 背景

- SmashHub は OSS として公開し、開発者・運営者を集めたい。
- 連合では、各インスタンスが同じルール（署名・検証・レート算出）のソフトウェアを動かしていることが信頼の前提になる。
- 改変したソフトウェアを非公開のまま運用されると、利用者や他の運営者がその挙動を確認できない。

## 検討した選択肢

1. **AGPL-3.0** — 改変版をネットワーク越しに利用させる場合もソースコードの公開が必要。Mastodon と同じ。
2. **GPL-3.0** — 配布時のみソースコードの公開が必要。サーバーとして運用するだけなら公開不要。
3. **MIT / Apache-2.0** — 制約が最も少ないが、改変版を非公開で運用できる。

## 決定

リポジトリ全体（ソースコードとドキュメント）を **GNU Affero General Public License v3.0（AGPL-3.0）** とする。ライセンス本文はリポジトリ直下の [LICENSE](../../LICENSE) に置く。

## 理由

- インスタンスの運営者がソフトウェアを改変した場合も、その利用者にソースコードを公開する義務があり、連合内の透明性を保てる。
- 特定の運営者・企業が改変版を囲い込むことを防ぎ、「特定の誰かに依存しない」というビジョンに合う。
- ドキュメントもコードと同じライセンスにし、リポジトリ全体を1つのライセンスで扱えるようにする。

## 影響

- インスタンスは、利用者が実行中のソフトウェアのソースコードを入手できるようにしなければならない（AGPL-3.0 第13条）。SmashHub は画面のフッターにソースコードへのリンクを表示し、運営者が改変した場合はそのリンク先を改変版のリポジトリに設定できるようにする。
- AGPL-3.0 と互換性のないライセンスの依存ライブラリ・素材は使えない。依存の追加時にライセンスを確認する。
- コントリビューションは AGPL-3.0 で提供されたものとみなす（CLA は求めない）。
