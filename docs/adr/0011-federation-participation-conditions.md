# 0011: 連合への参加条件を、記録と利用者の保護に絞る

- ステータス: Accepted
- 日付: 2026-10-27
- 関係者: @tacky0612

## 背景

[ADR 0007](0007-federation-open-to-commercial-sites.md) で、連合への参加に非営利を求めないことにした。一方で、非営利以外の約束事（任天堂の利用許可のない素材を使わない 等）は参加条件として残し、広告を掲載するサイトでもトラッキングは約束事に反するとしていた。

しかし、連合に参加するサイトは、それぞれ独立した運営者が独自の UI と運営方針で運営する。

- 素材の扱いやアクセス解析の設置は、各サイトの運営判断と法令・権利者との関係の問題で、SmashHub プロジェクトが判断・監督できるものではない。
- 参加条件を広く取るほど、既存の対戦サイトが参加しにくくなる。SmashHubプロトコルは「同じ対戦記録と同じ計算手順を共有する、レーティングの共通基盤」を目指しており、参加するサイトが多いほど記録が多くの場所に残る。
- 閉鎖予告の「30日以上前」は、個人運営のサイトには長すぎて守れない場合がある。

## 検討した選択肢

1. **ADR 0007 のまま（素材・トラッキングも参加条件）** — 参加サイトの水準はそろう。ただし、プロジェクトが監督できない事項を条件にしており、既存サイトの参加の障壁になる。
2. **参加条件を、連合で共有する記録と利用者の保護に絞る** — 素材・トラッキングは各運営者の責任とする。SmashHub プロジェクト自身の方針は変えない。

## 決定

選択肢 2 を採用し、ADR 0007 を置き換える。

- **SmashHub プロジェクト自身の方針**（ソフトウェアと、プロジェクトが運営・推奨するインスタンス）は変えない。
  - 任天堂の利用許可が出ている素材以外は使わない（[運営ポリシー](../policy.md) の「1. 商標・著作物の取り扱い」）。
  - 非営利で運用する。ソフトウェアに広告・課金・アフィリエイト・トラッキングを組み込まない（同「2. 非営利」）。
- **連合への参加には、営利・非営利を問わない**（ADR 0007 から引き継ぐ）。
- **連合に参加するサイトには、次を求めない。** 各運営者の判断と責任とする。
  - 任天堂の利用許可外の素材を使わないこと
  - アクセス解析・トラッキングを設置しないこと
- **連合への参加条件**（[運用者の約束事](../operations/server-covenant.md)）は、次に絞る。
  - 非公式のファンサイトであることを表示する（公式のサービスと誤認されないため）
  - 対戦記録を改ざんしない。架空のアカウント・対戦を作らない
  - 利用者の個人情報を連合で共有しない
  - 自サイトのログを連合先に提供し続ける
  - 閉鎖する場合は、可能な限り **7日以上前** に予告する（30日から短縮）
  - 利用者が求めた場合、対戦履歴のエクスポートとアカウント移行を妨げない
- 各運営者の営利活動・素材の利用・アクセス解析等や、それによる任天堂株式会社その他の権利者の権利の侵害・法令違反について、SmashHubプロトコルおよび SmashHub プロジェクトは責任を負わない。責任は各運営者が負う（ADR 0007 から引き継ぐ）。
- 約束事に反するインスタンスは、各インスタンスが連合ポリシー（拒否リスト）で拒否できる。

## 理由

- 参加条件を、プロトコルが扱う範囲（共有する記録の誠実さと、連合に出す情報）に合わせると、条件を守っているかを連合の側で判断しやすい。
- 既存の対戦サイトが、今の運営方針を大きく変えずに参加できる。
- プロジェクト自身の方針（素材を使わない・非営利）は変えないので、プロジェクトの立場と免責の線引きは保たれる。

## 影響

- 運用者の約束事・運営ポリシー・データ保護・SmashHubプロトコル・既存の対戦サイト向け入門・紹介サイトの記述を、プロジェクト自身の方針と参加条件に分けて書き直す。
- 連合先に、任天堂の素材を使うサイトや、アクセス解析を設置するサイトが含まれうる。SmashHub のインスタンスがそれらのサイトの記録を取り込んでも、取り込むのは SmashHubプロトコルの事実（アカウント ID・表示名・対戦記録）だけで、素材やトラッキングは持ち込まれない。
- 権利者から問題視されるサイトが連合に増えた場合は、拒否リストでの対応か、参加条件の見直し（新しい ADR）を検討する。
- 閉鎖予告の期間を短くしたため、利用者の移行と記録の最終的な複製は、予告から閉鎖までの短い期間で済ませる必要がある。ミラーと記録の複製（ロードマップ Phase 2〜3）で、閉鎖時の記録の保全を補う。
