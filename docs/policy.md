# 運営ポリシー

このポリシーは SmashHub の **開発プロジェクト自身**（SmashHub のソフトウェアと、プロジェクトが運営・推奨するインスタンス）の方針です。
連合に参加する他のサイト（SmashHub のソフトウェアを使う他の運営者を含む）には、このポリシーのうち [サーバー運用者の約束事](operations/server-covenant.md) に定める参加条件だけを求めます。素材の扱い（「1.」）・非営利（「2.」）・アクセス解析の有無は、各運営者の判断と責任です（[ADR 0011](adr/0011-federation-participation-conditions.md)）。
連合への参加条件は [サーバー運用者の約束事](operations/server-covenant.md) にまとめています。

> [!NOTE]
> このドキュメントは法的助言ではありません。判断に迷う場合は「使わない・やらない」を選び、Issue で相談してください。

## 1. 商標・著作物の取り扱い

「大乱闘スマッシュブラザーズ」は任天堂株式会社の登録商標です。ゲームに関する著作権・商標権は任天堂株式会社および関連する権利者に帰属します。

### 1.1 基本方針

**任天堂の利用許可が出ている素材以外は採用しません。** 許可の範囲がはっきりしない素材も採用しません。

### 1.2 使わないもの

リポジトリ・サービス画面・ドキュメント・SNS 告知のいずれにおいても、以下を含めません。

- ゲーム画面のスクリーンショット・動画からの切り出し
- ファイター（キャラクター）の画像・ストックアイコン・シルエット・3D モデル
- ステージの画像
- 公式ロゴ・タイトルロゴ・シリーズマーク（スマッシュボールのマーク等）
- 公式のフォント・効果音・BGM
- 上記を模写・トレースした二次的な素材

**例外: 通報の証拠としての画像。** 利用者が通報の証拠として添付するスクリーンショット（ゲームの結果画面等）は、運営者だけが閲覧できる非公開の一時保管とし、対応完了後に削除します。公開・連合での共有・再利用は行いません。

### 1.3 使い方に配慮するもの

- **ゲーム名・ファイター名・ステージ名のテキスト表記** — 対戦記録の内容を示すために必要な範囲で、テキストとして使用します。ロゴ風の装飾はしません。
- **プロジェクト名「SmashHub」** — 公式サービスと誤認されないよう、ロゴやデザインで公式の意匠に寄せません。
- **ファイターの識別表示** — 画像の代わりに、テキスト・略称・プロジェクト独自の汎用的な配色などで表現します。

### 1.4 素材の採用手順

新しい素材（画像・フォント・アイコン等）を追加する PR では、以下を PR 本文に記載します。

1. 素材の出典
2. ライセンス（OSS 互換のライセンスであること）
3. 任天堂の著作物を含まない、または利用許可の範囲内であることの根拠

### 1.5 表示義務

サービスのフッター等に、次の趣旨の表示を行います。

> 本サービスは有志による非公式のファンサイトであり、任天堂株式会社とは一切関係ありません。
> 「大乱闘スマッシュブラザーズ」は任天堂株式会社の登録商標です。

### 1.6 権利者からの申し出

権利者から申し出があった場合は、その内容に従い速やかに対応します。

## 2. 非営利（開発プロジェクト自身の方針）

**SmashHub プロジェクトは、サイト運営で収益を得ません。** プロジェクトが運営・推奨するインスタンスも同じ方針とします。

- 広告を掲載しない
- 有料プラン・有料機能・課金アイテムを作らない
- 利用者のデータを販売・提供しない
- アフィリエイトリンクを置かない

- SmashHub のソフトウェアに、広告・課金などの収益化の機能を組み込まない

サーバー費用の扱い（運営者の自己負担を原則とし、寄付の受け入れ可否を含む）については、非営利の原則を崩さない範囲でコミュニティで議論して決めます。決まるまでは **寄付も受け付けません**。

### 2.1 他の運営者について

SmashHub のソフトウェアを使う運営者や、SmashHubプロトコルを独自に実装する他のサイトは、**営利・非営利を問わず** 連合に参加できます。参加には [運用者の約束事](operations/server-covenant.md)（記録の誠実な取り扱い・利用者の保護・閉鎖時の予告等）への同意が必要です。素材の利用やアクセス解析の設置は、参加条件ではありません（[ADR 0011](adr/0011-federation-participation-conditions.md)）。

各運営者の営利活動・素材の利用・アクセス解析等や、それによる任天堂株式会社その他の権利者の権利の侵害・法令違反について、SmashHub プロジェクトおよび SmashHubプロトコルは責任を負いません。責任は各運営者が負います。

## 3. プレイヤーのデータ

### 3.1 対戦記録は公開・複製される

SmashHub の性質上、**確定した対戦記録は公開され、連携する複数のサーバーに複製されます**。これは記録を失わないための中核的な仕組みです。アカウント登録時にこの点を明示し、同意を得ます。

### 3.2 最小限の個人情報

- 対戦記録に含めるのは、アカウント識別子・表示名・使用ファイター・勝敗・日時など対戦の記録に必要な情報のみです。
- **インスタンスは個人情報を保持しません。** 氏名・メールアドレス・電話番号・パスワード・外部サービスのアカウント名などを受け取らず、保存しません。
- ログインは外部の認証プロバイダー（Discord / Google）に任せ、インスタンスにはプロバイダーの利用者 ID を元に戻せない形でハッシュ化した値だけを保存します（→ [データ保護](security/data-protection.md)）。
- フレンドコードや外部 SNS アカウントなど連絡先情報は記録に含めません。

### 3.3 削除とエクスポート

- プレイヤーは自分の対戦履歴をいつでもエクスポートできます。
- アカウント削除時は、プロフィール情報を削除し、対戦記録上の識別子を仮名化します。対戦相手の記録やレートの整合性を保つため、対戦記録そのものは仮名化された状態で残ります。この扱いは登録時に明示します。

## 4. セキュリティ

セキュリティの方針は [セキュリティポリシー](security/README.md) に、脆弱性の報告方法は [SECURITY.md](../SECURITY.md) に定めます。

## 5. 行動規範とモデレーション

- 開発コミュニティでは [行動規範](../CODE_OF_CONDUCT.md) に従います。
- 各サーバーのモデレーション（通報対応・利用停止）は各サーバーの運営者が行います。
- 不正（虚偽報告・複数アカウントによるレート操作・嫌がらせ）への対応方針はロードマップに沿って整備します。
