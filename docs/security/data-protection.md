# データ保護

> ステータス: **Draft**。

## 1. 方針: インスタンスは個人情報を保持しない

SmashHub のインスタンスは、アカウント作成・利用のために **個人情報を受け取らず、保存しません**。

| 保存しないもの | 理由・代わりの手段 |
|---|---|
| 氏名・住所・電話番号・生年月日 | サービスに不要 |
| メールアドレス | 認証は外部プロバイダーに任せる。お知らせはサービス内で表示する |
| パスワード | 外部プロバイダーで認証する |
| 外部プロバイダーのユーザー名・アバター・利用者 ID | 元に戻せない識別子ハッシュだけを保存する（→ 3.） |
| 外部プロバイダーのアクセストークン | 利用者 ID の取得後に直ちに破棄する |
| フレンドコード・外部 SNS アカウント | 対戦相手との連絡は対戦ルーム内でその場限りで行う |

## 2. 保存するもの

| データ | 内容 | 公開範囲 | 保持期間 |
|---|---|---|---|
| 識別子ハッシュ | ログイン時に同じ人を見分けるための値（→ 3.） | ホームインスタンスのみ | アカウント削除まで |
| アカウント ID・公開鍵 | 鍵から導出した ID | 連合で共有 | 永続（削除時は仮名化） |
| 表示名・プロフィール | 利用者が自分で入力したもの | 連合で共有 | アカウント削除まで |
| アカウントの署名鍵（秘密鍵） | 暗号化して保存 | ホームインスタンスのみ | アカウント削除まで |
| リカバリーキー（公開鍵のみ） | 復元時の本人確認用 | 連合で共有 | 永続 |
| 対戦記録 | 両者署名付きの記録 | 連合で共有 | 永続 |
| セッション | セッション ID・有効期限 | ホームインスタンスのみ | 失効まで |
| 対戦ルームのメッセージ | 対戦相手との連絡 | 対戦の当事者のみ | 対戦終了後 **7日** で削除（初期値） |
| 他インスタンスのアカウントの公開情報 | 連合で取り込んだアカウント ID・表示名・ホームインスタンス | 連合で共有（公開情報） | 取り込んだログに従う |
| 他インスタンスの対戦募集 | 配信された募集（アカウント ID・1戦目のファイター・レート差の条件） | 自インスタンスのみ | 30秒で失効（一時データ） |
| 対戦設定 | 拒否ステージ・スイッチ・マッチング条件（連戦・接続方法・レート差）・配信 / 動画化の設定・ゲーム内の名前 | ホームインスタンスのみ（対戦中は必要な範囲を相手とホストに開示） | アカウント削除まで |
| ブロック | ブロックした相手のアカウント ID | ホームインスタンスのみ（本人にのみ表示） | シーズン終了まで |
| 対戦マナーの目安 | 報告しなかった回数・中止の回数・食い違いの回数 | ユーザーページで公開 | 現シーズンの回数のみ。シーズン終了でリセットし、過去の回数は保持しない |
| 通報 | 通報内容、証拠のスクリーンショット（3枚まで） | 運営者のみ（通報者は相手に伝えない） | 対応完了後 **30日** で削除（初期値）。モデレーションの記録（段階・理由）は残す |
| アクセスログ | IP アドレス・日時・リクエスト（メソッド・パス・ステータス・処理時間。クエリ文字列は含めない） | ホームインスタンスのみ | **14日**（初期値） |

> [!NOTE]
> 表示名やプロフィール、対戦ルームのメッセージに、利用者が自分で個人情報を書き込む可能性があります。入力画面で注意を表示し、プロフィールに連絡先を書かないよう案内します。
> また、IP アドレスはセキュリティと不正対策のためだけに短期間保持し、連合では共有しません。

## 3. 識別子ハッシュ

外部プロバイダーの利用者 ID をそのまま保存すると、インスタンスの DB からその人の Discord / Google アカウントを特定できてしまいます。そこで、次の値だけを保存します。

```
identifier_hash = HMAC-SHA256(key = instance_pepper, message = provider || ":" || provider_user_id)
```

- `instance_pepper` はインスタンスごとのランダムな秘密値で、**DB とは別に** 設定（環境変数・シークレットファイル）として保管します。
- DB だけが漏えいしても、ペッパーなしでは利用者 ID を総当たりで照合できません。
- インスタンスごとにペッパーが異なるため、**複数のインスタンスの DB を突き合わせても同じ人だと分かりません**。
- ペッパーを失うと既存の利用者がログインできなくなるため、運営者はペッパーを安全にバックアップする必要があります（失った場合はリカバリーキーで紐づけ直します）。

> [!WARNING]
> DB とペッパーの両方が漏えいした場合、攻撃者は「特定の Discord ID の人がこのインスタンスにいるか」を確認できます。ペッパーは DB と同じ場所・同じバックアップに置かないでください。

## 4. 連合で共有されるデータ

連合で共有するのは **アカウント ID・公開鍵・表示名・プロフィール・対戦記録** だけです。いずれも個人情報を含まない設計です。
識別子ハッシュ・セッション・アクセスログ・対戦ルームのメッセージは共有しません。

## 5. 利用者の権利

| 操作 | 内容 |
|---|---|
| エクスポート | 自分のプロフィールと対戦履歴をダウンロードできる |
| 表示名・プロフィールの変更 | いつでも変更できる（変更は連合に配信される） |
| プロバイダーの紐づけ解除 | 識別子ハッシュを削除する（最低1つは残す） |
| アカウント削除 | 識別子ハッシュ・署名鍵・プロフィール・セッションを削除し、連合に `AccountPseudonymized` を配信する。対戦記録は相手のレートの整合性のため、仮名化された状態で残る |

対戦記録が削除後も仮名化された形で残ることは、登録時に明示して同意を得ます（→ [運営ポリシー](../policy.md)）。

## 6. 運営者の責任

- ここに定めた以上の情報を収集しないこと。SmashHub のソフトウェアは、利用者を追跡するアクセス解析ツール・トラッキング・広告タグを組み込まない。プロジェクトが運営・推奨するインスタンスは、これらを設置しない（連合に参加する他のサイトでの扱いは各運営者の責任 → [運用者の約束事](../operations/server-covenant.md)）。
- 外部の CDN・解析サービス等に利用者の情報を送る構成にしないこと。
- アクセスログの保持期間を守ること。
